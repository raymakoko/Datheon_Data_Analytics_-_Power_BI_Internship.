# Datheon_Data_Analytics_-_Power_BI_Internship.
Transform corporate datasets into actionable executive dashboards with Python and Power BI.

# Task 1
## Build an interactive Power Bi sales/profit dashboard
- The dataset was for a superstore.
- Transformed raw sales records into an interactive executive dashboard with:
   1. KPI scorecards
   2. Dynamic date slicers
   3. Regional performance treemaps
   4. Product profitability matrices.
- It was discovered that the superstore had:
      1. **Total sales** of $2.3 million.
      2. **Total orders** of 5.01 thousands.
      3. **Total Profit** of $286.40 thousands.
      4. **Profit Margin** of 12.47%.
